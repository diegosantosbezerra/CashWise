# CashWise 
Aplicativo de educação financeira voltado para jovens e pré-adolescentes. Desenvolvido como Trabalho de Conclusão de Curso para o Curso Técnico em Desenvolvimento de Sistemas ETEC de Itaquera.

## Tecnologias usadas  
- HTML, CSS, JavaScript, Bootstrap  
- Firebase (para o app móvel)
